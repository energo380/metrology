# Журнал движения СИ при поверке в ЦСМ

Сайт метрологии АО «Новосибирская птицефабрика»: учёт движения средств измерений
Цех → Метрология → ЦСМ → Метрология → Цех. Устроен так же, как «Заявки на материалы» (snabgenie):

- `index.html` — страница сайта на GitHub Pages;
- Google Таблица — база данных;
- `Code.gs` — серверный скрипт Google Apps Script; функция `setup` сама создаёт таблицу со всеми листами.

## Роли

| Кто | Пароль | Что может |
|---|---|---|
| Метролог (ФИО-1, ФИО-2, ФИО-3) | у каждого свой | вносит приборы, ставит даты, отмечает этап сразу у нескольких приборов, выбирает «Кто вносит» |
| Администратор | свой | всё то же + исправляет закрытые записи, удаляет, смотрит журнал правок |

Запись **закрывается** через 10 дней после даты «4. Метрология→Цех» (срок меняется на листе «Настройки»).
После этого метролог её не изменит, а администратор может, и тогда в колонку «Изменения» добавится пометка «Корректировка администратором дд.мм.гггг чч:мм».

## Установка (один раз, ~10 минут)

### 1. Скрипт и таблица
1. Создайте пустую Google Таблицу (sheets.new) → **Расширения → Apps Script**.
   *Можно и без таблицы: новый проект на script.google.com — тогда скрипт создаст таблицу сам
   и напишет ссылку на неё.*
2. Удалите всё в `Код.gs` и вставьте содержимое `Code.gs` из этого репозитория.
3. Чтобы перенести 297 записей из Excel: **＋ → Скрипт**, назовите `Import` и вставьте содержимое
   файла `Import.gs` (его выдали отдельно; **в репозиторий его не кладём**, репозиторий открытый).
4. Сохраните (💾). В списке функций вверху (рядом с кнопкой «Выполнить») выберите **`setup`** — она первая в списке —
   и нажмите **Выполнить** → разрешите доступ (Google спросит: «Дополнительно → Перейти к проекту» → «Разрешить»).
5. Откройте **Журнал выполнения**. Там будут:
   - ссылка на таблицу;
   - **пароли** для ФИО-1, ФИО-2, ФИО-3 и Администратора (случайные, 6 цифр) — запишите их;
   - строка «Всё в порядке».
6. В таблице на листе **«Пользователи»** замените ФИО-1…3 на настоящие ФИО. Пароли можно поменять там же.
   Файл `Import.gs` после загрузки можно удалить из проекта.

`setup` можно запускать повторно: он только добавляет недостающее и не трогает данные.
Функция `check` проверяет листы, пароли и часовой пояс.

### 2. Веб-приложение
1. **Начать развертывание → Новое развертывание** → тип **Веб-приложение**:
   - Запуск от имени: **Я**
   - У кого есть доступ: **Все**
2. **Развернуть** → скопируйте **URL веб-приложения** (заканчивается на `/exec`).

### 3. Сайт
1. В `index.html` этого репозитория замените строку
   `const API_URL = 'ВСТАВЬТЕ_СЮДА_АДРЕС_ВЕБ-ПРИЛОЖЕНИЯ';` — вставьте URL из шага 2.
   (На GitHub: открыть файл → ✏️ → правка → Commit changes.)
2. Откройте настройки **репозитория** (не аккаунта): https://github.com/energo380/metrology/settings/pages →
   **Source: Deploy from a branch → Branch: main, папка / (root) → Save**.
3. Через 1–2 минуты сайт откроется: **https://energo380.github.io/metrology/**

## Обновление скрипта
После правки `Code.gs`: **Начать развертывание → Управление развертываниями → ✏️ → Версия: новая → Развернуть**.
Адрес при этом не меняется.

## Листы таблицы
- **Приборы** — журнал. «Статус» и «Дней всего» скрипт пересчитывает при каждом сохранении.
  Править вручную в таблице можно, но статус обновится только после сохранения с сайта.
- **Пользователи** — ФИО, пароль, роль («метролог» / «администратор»), активен.
- **Места** — список для выпадающего меню «Цех / место». Новое место можно просто вписать в карточке прибора.
- **Журнал правок** — кто, когда, какое поле, было → стало.
- **Настройки** — дни до блокировки (10), порог подсветки (20), название для печати.

## Правила, перенесённые из Excel
- Статус: Поступил в метрологию → В ЦСМ на поверке → Вернулось из ЦСМ → Выдано в цех.
- «Дней всего» = последняя дата − дата этапа 1. Зелёный, если меньше 20 дней, красный, если 20 и больше.
- Даты этапов должны идти по порядку. Этапы 2–3 можно пропустить (поверка на месте). На сайте нельзя
  сохранить даты не по порядку, поэтому статус «Некорректная дата» не возникнет.
- Кнопка «Сегодня» у каждой даты заменяет кнопку «ДАТА» из Excel.
